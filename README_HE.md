# Module E Academy – גרסת ניסיון ל־Render + Supabase

זו גרסת פיילוט בלבד. **אין להזין פרטי תלמידים אמיתיים או לקיים בחינות מחייבות** לפני בדיקות אבטחה, תקינות ושימושיות. הכניסה משתמשת בסיסמאות אישיות, לא בטלפונים.

## העלאת קבצים ל־GitHub
1. פתח את המאגר הפרטי `module-e-academy` ולחץ `Add file` ואז `Upload files`.
2. העלה את `app.py`, `content_bank.py`, `requirements.txt`, `.gitignore`, `students_example.csv`, `README_HE.md` לתיקיית השורש. אל תעלה את ZIP.
3. לחץ `Commit changes`.

## Supabase
1. פתח את הפרויקט ב־Supabase.
2. לחץ `Connect` > `Session pooler` (פורט 5432), המתאים לחיבורים מ־IPv4. העתק את connection string המלא. אין לשתף אותו עם איש.
3. החלף את `[YOUR-PASSWORD]` בסיסמת מסד הנתונים שלך. אם הסיסמה כוללת תווים מיוחדים, נדרש URL encoding או איפוס לסיסמה ארוכה שהורכבה מאותיות ומספרים.
4. ב־Render הגדר את מחרוזת החיבור כמשתנה סביבה `DATABASE_URL`, ולא בקוד GitHub.

## Render
1. Dashboard > New > Web Service > Connect your GitHub account > choose private repo `module-e-academy`.
2. Language: Python, Plan: Free (אם זמין באזור שלך).
3. Build command: `pip install -r requirements.txt`
4. Start command: `gunicorn app:app --workers 1 --threads 4 --timeout 120`
5. Environment variables:
  - `DATABASE_URL` : מחרוזת החיבור המאובטחת מ־Supabase
  - `SECRET_KEY` : מחרוזת אקראית ארוכה וסודית (לפחות 32 תווים)
  - `TEACHER_PASSWORD` : סיסמת מנהל חזקה (לפחות 16 תווים)
  - `RENDER` : `true`
  - `GRACE_SECONDS` : `10`
6. Create Web Service. בדוק `/health` (אמור להציג `{"status":"ok"}`).
7. פתח `/teacher/login` עם סיסמת המנהל שלך.

## הניסיון הראשון
1. לחץ 'ייבוא תלמידים' והעלה עותק של `students_example.csv` עם פרטי **דוגמה בלבד**.
2. מאגר והקצאות > בחר פעילות, הקלד כיתה `יא3`, קבע חלון פתיחה וסגירה, בחר תרגול והקצה.
3. בדוק דרך חלון גלישה בסתר כניסה כתלמיד הדגמה. שם וסיסמה רשומים בקובץ הדוגמה.
4. פתח בחינה ונסה יציאה מהלשונית, וחזור לראות סטטוס במסך התלמיד ודוח המורה.

## מגבלות גרסת הפיילוט
- שעות הפתיחה והסגירה נקלטות כשעון ישראל; טבלת ההקצאות מציגה UTC כרגע. יש לשפר את התצוגה לפני שימוש רחב.
- משימה ניתנת להקצאה לכיתה כולה בלבד; הקצאה פרטנית תתווסף בהמשך.
- אין עדיין עורך חזותי להוספת משימות. יש 18 משימות מקוריות מובנות.
- דוח האירועים המלא ושחרור פסילה טרם יושמו בממשק.
- ניטור מעבר ללשונית הוא אינדיקציה בלבד, אינו מונע שימוש במכשיר נוסף.
- בתוכנית החינמית השירות עלול להירדם. ייתכן עיכוב בפתיחה הראשונה.
- נדרשת בדיקת אבטחה לפני שימוש בנתוני תלמידים אמיתיים. לשימוש עם תלמידים קטינים יש לפעול לפי נהלי בית הספר.
